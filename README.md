# HwpExamAssembler for SNUHS

서울대학교사범대학부설고등학교 시험지 수합·편집기의 Windows 배포 저장소입니다. 한컴 한글이 설치된 PC에서 사용하세요.

**[최신 Windows 실행 파일 다운로드](https://github.com/CauchyRiemannEquations/HEAforSNUHS/releases/latest/download/HWPExamAssembler-School-Windows.exe)** · [버전별 변경 사항](https://github.com/CauchyRiemannEquations/HEAforSNUHS/releases)

1. 실행 파일을 열고 **새 시험지 수합**에서 과목명과 시험일을 입력한 뒤 출제 파일을 추가하세요. 학교 빈 양식이 내장되어 있습니다.
2. 수합본을 **한글에서 확인**으로 열어 두면 편집기에서 문항을 옮길 때 한글도 해당 문항으로 이동합니다. 난이도와 시험 정보는 편집 화면에서 바꿀 수 있습니다.
3. 다음 실행부터 앱이 GitHub 로그인 없이 새 버전을 확인합니다. 작업을 시작한 뒤 업데이트가 준비되면 다음 실행 때 적용합니다.

시험지와 출제 파일은 PC의 한컴 한글에서 처리합니다. 자동 업데이트는 GitHub에서 릴리스 정보와 실행 파일을 내려받습니다.
